== uncertainty
  n = 230 labeled pairs, 3 labeled unsure and excluded from precision and recall; the metrics rest on that small sample.
  The sample is stratified by design (exact-id, hard-common-name, clear-non-match, about a third each), not random, so these are not population rates. Pooled precision and recall depend on the mix.
  Pooled precision does not measure the probabilistic path when the export left out pairs whose context agrees (includeAgreeingContext false), and the exact-id stratum is selected by the same shared identifier rule the exact-id path accepts on, so its accepts agree with it by construction. A high pooled precision therefore says nothing about the probabilistic or deterministic-bibliographic accept paths.
  Intervals are Wilson 95% intervals for a simple binomial, which ignores the stratification and the clustering of pairs by author.
  Recall is measured over candidate pairs only. Matches that blocking never proposed are not in the sample, so true recall is lower or equal.
  Gold labels come from one reviewer. No label in this file was made with a suggestion visible, so there is no suggestion to agree with.
  DBLP names carry numeric homonym suffixes, so many DBLP-DBLP labels are decided by DBLP's own disambiguation. Scores against those labels measure agreement with DBLP, not independent truth.
  Thresholds are provisional and hand-set. The sweep reads them off this sample only; a change chosen from it would be tuned to the evaluation set and needs a separate sample.
  Export manifest: includeAgreeingContext false; 5766 same-name agreeing-context pairs were excluded from the sample.
  This gold file has no with-suggestion label: 77 labels were reviewed blind in pass 2 and 153 in pass 3, a blind re-review of the pass-1 pairs. The pooled and per-stratum numbers mix the two passes; read the by-pass section. The reviewer had seen every pair before, with suggestions, so memory may still anchor the labels.
